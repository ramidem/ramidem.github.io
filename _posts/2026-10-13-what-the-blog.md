This blog is a set of notes. Each note is a Jekyll post: a markdown file in `_posts/`.

## Folders

A note's folder is its `category` in front matter. This one sits in `jekyll`:

```yaml
category: jekyll
```

Folders are one level deep: no folders inside folders. **All Notes** shows every note, whatever its folder.
